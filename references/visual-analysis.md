# 15张参考逐维度分析

## 阅读口径

编号严格按创建者提供的顺序。公开版不附第三方原图；原始来源文件名记录见 `sources.json`，这些记录不代表已获得图片再分发许可。使用者可自行提供有权使用的 `source-images/R01.jpg` 至 `R15.jpg`。以下色值是目测近似、坐标是截图归一化估计，允许因缩放/摄影变形有约1–2%误差。它们用于重建版式关系，不代表获得了原网站模板或精确字体。

坐标统一用 `[x,y,w,h]`，左上角为原点，值为0–1。`C`代表整张展示画面，`B`代表封面书面，`P`代表单页。所有照片以视觉内容为准，不把截图里的书或字样再当新照片内容。图6/7/9/11/12是两组跨页的陈列图；图10/15是跨页局部特写；图13是直接的集合页。

## 内页：逐图拆解

### R13 果味：3×3集合索引页

## 视觉系统汇总

| 维度 | 保持的逻辑 | 可随用户素材改变的部分 |
|---|---|---|
| 层级 | 展示底→书/纸→照片→极少文字/装饰 | 背景素材与具体书面色 |
| 几何 | 对应模板的小窗、比例、主次、对齐、留白 | 根据构图主动裁剪、放大主体、拉开景别；保持主体可辨和照片框结构 |
| 色彩 | 2–3个大面积色、1个强调色；同书复用 | 从照片选主题色，不机械复制每张参考色 |
| 线框 | 黑细线/粉紫强调边、页缝细线 | 在规定范围调整粗细 |
| 装饰 | 方块、编号、椭圆、圆字标、少量星或点环 | 根据主体避让位置；有意义的原创小元素 |
| 文字 | 很小、稀疏、靠近照片或页边 | 中文短标题、用户真实信息 |
| 质感 | 轻纸感、微书脊、弱阴影、照片保留原质感 | 外底可由AI生成；不强加旧污渍 |
| 叙事 | 主体与细节互相回应 | 素材决定具体故事，不能编造关系和日期 |

不要把所有家族混到一页。原参考的印刷颗粒与摄影模糊，不等于最终应故意导出低清；以清晰原照片＋轻微材质完成。
