# AI模型＋代码生产流程

## 运行前的判断

本包是可执行排版器与视觉选择规则，不是训练后的神经网络权重。图片理解调用指定豆包2.0-lite，材质生成按需调用指定Seedream5.0 Pro，代码负责可控几何和原照片嵌入。不得宣称脚本已自动理解人物关系或已训练专用模型。

默认选一组跨页作为一张内页成图；当用户明确指定参考的双跨页陈列时使用 `stack`。R10/R15的局部放大要设置 `view_crop`，不要压缩照片或改变书页真实比例。

**输出边界：仅静态PNG。** 可以编写和运行静态裁剪、合成、排版脚本；不得生成动画、交互、网页翻页、HTML/JavaScript动态代码、GIF或视频。

## 1. 原片盘点与语义计划

先查看所有用户原片。运行 `plan` 生成尺寸、简易色板和数量骨架，再运行 `ark_book.py analyze` 获取豆包的语义建议，由执行代理核对并转换为渲染计划（见 [模型调用](models.md)）：

- `story`：一两句话说明这些照片实际如何相连，只使用可见事实或用户提供的信息。
- 每张照片的 `note`：主体、场景、原景别与目标景别、照片作用（环境/主角/细节）、保护区域和裁剪理由。
- `slots[].crop`：用[x0,y0,x1,y1]记录主动裁剪范围。素材景别相近时，选主体明确的一张裁成近景或细节，其他照片保留环境，形成层次；保持参考模板的照片框尺度和位置。
- `focus`：裁切中心，0–1；椭圆四角不可用，重要脸部须在椭圆中间安全区。多人照/扁长景不适合则选矩形模板，不能强行剪掉人。
- `palette`：整书选3–5个协调页面底色和1个贯穿强调色；按模板保留明暗/冷暖关系。
- `pages`：固定数量内完成分组、槽位分配，内页不得漏原片。若模板槽位数超过图片数，换模板或明确记录复用；不要自动循环照片填满所有位置。

封面U01保持不变，除非用户另有指定。其余图可依据语义重排；编号按展示顺序，不能借编号暗示未知时间线。程序只能做基于尺寸与数量的初始建议，无法验证脸部裁切或真实关系。

## 2. 选择最接近的版式

| 输入组特征 | 优先内页模板 | 槽位数 |
|---|---|---:|
| 主体/环境两张，一张适合竖向椭圆 | full_oval / oval_full | 2 |
| 大主体＋两张表情/动作 | full_double_oval | 3 |
| 两张横向细节＋竖向环境 | offset_full | 3 |
| 主体＋一个连续室内场景 | full_split | 2（右侧同图切片） |
| 两张横图、对照或空间呼应 | diagonal | 2 |
| 大图＋四个日常碎片 | hero_scatter / scatter_full | 5 |
| 两横图＋四张纪念照 | offset_polaroid | 6 |
| 两张镜中/动作图＋大场景＋小场景 | double_oval_scene | 4 |
| 主体＋横向纪念照片 | full_frame | 2 |
| 满版主图＋六个碎片 | full_index | 7 |
| 四张散点＋竖椭圆主体 | scatter_oval | 5 |
| 明确集合页/多图只输出一张 | collection | 1–9 |

表中复杂模板不意味着增加输入：默认4–9张的内页分组通常2–3张，因此多用基础模板。需要复杂版式时可在固定成图数量内重分组，或用明确的 `slots` 仅保留对应模板中适用的槽位；保留主图—小图、对齐与留白结构，不用随机坐标。如果减少槽位造成空页，必须重新设计分组。

## 3. 按需生成外底

默认浅米灰纯色外底由代码生成。只有需要摄影材质或原创装饰资产时，使用 `ark_book.py background` 调用指定Seedream端点；配置与凭据设置方式见 [模型调用](models.md)。保留实际返回路径，不预写虚构路径，不默认切换模型。
提示词模板（生成资产，不生成整本书）：

> 生成电子照片书的纯展示背景，竖版3:4。背景材质为【绿色斜向细纤维/灰白柔软织物与错列小白点/藏蓝细织布与米灰小点/浅蓝白格布/灰白旧纸/深灰朦胧室内窗光】。配色【本书选择的颜色】，光线柔和统一，中央约70%区域安静、低对比，外围仍有自然材质。参照所附参考的底图质感和色彩密度，不复制书籍、照片、人物、文字、Logo或水印。不要任何书、相框、拼贴、纸页、摆拍道具和标题；交付仅背景。

绿色纤维不应变成草坪；点纹布不应变成大圆点图案；暗窗影不要强光穿过书面。只生成一张选定底图供整书复用。代码中的fiber/dark是可用的简化替代，不等同AI摄影材质复刻，使用时如实说明。

几何装饰由代码画。若用户明确需要类似R11的小型玩具点缀，可生成原创小装饰透明PNG，再手动扩展合成代码；随包渲染器不自动调用图片模型，也不默认支持外部贴纸层，不能声称已加载不存在的资产。

## 4. 精确排版

依赖Python 3.10+与Pillow。优先使用环境已有运行时；Codex桌面可从workspace dependency工具取得Python路径。未安装Pillow时在任务环境安装，不修改系统Python。提供中文字体时使用环境可用且有授权的字体；默认探测PingFang/Noto CJK/微软雅黑，Linux仅有DejaVu时需补充CJK字体。

使用 `render_book.py` 输出。默认1600×2133，照片EXIF方向会校正、遮罩/框/文字由代码确定。图像缓存只为渲染加速，不改写原片。需要更细控制时修改计划 `slots`，不是让AI随意重绘照片。小于目标分辨率的照片会产生警告，应缩小展示尺度或保留清晰度限制，不虚构高清细节。

## 5. 视觉验收（必须打开成图）

- 数量：N=1/2/3/4/6/7/9以及只出一张的规则正确，封面只出现一次。
- 原片覆盖：所有U图至少可辨认出现一次；封面确为U01；同图切片没有被当新输入。
- 参考匹配：封面照片窗约书面9%；book框、页缝、单页宽高、椭圆方向、照片主次、留白与选定参考一致。
- 身份与裁切：不换脸、不重画宠物特征；允许有意的主体近景或局部特写，避免无意切断关键脸部、动作或物件。椭圆边线和方块不遮挡主体。若装饰挡脸，移除或针对该页调整装饰代码，不能为了模板死守错误位置。
- 景别与疏密：原片景别接近时，是否通过选择性裁剪和主体放大产生层次；是否保留环境、较疏区域和明确视觉重心，避免所有主体同样大、每个槽位同样密。
- 静态边界：成品仅为规定数量的静态图片，无动态代码、交互页面、翻页动画、GIF或视频。
- 字体与阅读：没有方框缺字、乱码或文字溢出；主标题低调，短句来自真实信息；有足够对比度，深色底可用浅黄字。
- 书本感：书脊轻、纸页薄、阴影自然；不是厚立体卡片，也不是平铺照片拼图。
- 系列一致：同底图、同文字家族、重复主色；内页布局有变化但没有换成不相关风格。

程序 `validate` 不替代视觉验收。只有实际生成并打开验证的内容才能称为“已完成”。离线渲染验证不代表已执行图片理解或背景生成接口。
